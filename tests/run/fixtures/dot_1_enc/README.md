# dot_1_enc at trace levels task and stall

A recorded SNAX-GVSoC run of one accelerator of two groups in one streamer set (D148), so CI converts it without GVSoC (`tests/run/test_dot1.py`): dot_1_enc, the accelerator `dot` of groups `vmul` and `vsum`, a task each, the other group's movers idle. Made in SLOT1 F3 in snax-forge's image at snax-forge `slot1-f2b` plus F3's readers and snax-gvsoc `1e988679` (G1, one streamer per set, here `snax_acc0/streamer_dot`):

    pixi run flow recipes/dot/dot_1_enc.json --platform platforms/snax_forge.json --trace task
    pixi run flow recipes/dot/dot_1_enc.json --platform platforms/snax_forge.json --trace stall

and copied from `out/flow/dot_1_enc_task/` as vecadd's (`../vecadd/README.md`): `run/events.log`, the three description files of `gen/` and its `manifest.json` (each set's streamer trace path, C§16), `tasks.json`, `design/design_point.json` (its `graph_from` made relative), `check.json` (the profile's `total_cycles` and `functional_check`, each task's group with it) and `elf_symbols.json` (`run.json`'s, the ELF `sw/forge.elf` sha256 `8cddf4e917539c67`); from `out/flow/dot_1_enc_stall/` its `run/events.log` as `events_stall.log` (the same ELF, the same 304-cycle window). The run: 304 cycles, COUNTERs `mult_vmul` 19 and `sum_vsum` 19. This folder was `dot_1/` until F3, recorded with the groups `mul` and `sum` when `recipes/dot_1.json` was this encapsulated form; since SLOT1 F2b that form is `recipes/dot/dot_1_enc.json`, and `../dot_1/` holds dot 1's two accelerators. Made again the same way when snax-gvsoc's grammar (`docs/EVENTS.md`) or the generated files change. Made again in B2 R1 by the same two commands at snax-forge `b491c60` and snax-gvsoc `deec8e80` (`vmul` the BRM `simd` over `SimdLanes`): only the names changed, in `accelerator.json` (`brm`, `datapath`), `design_point.json` (`brm`) and `snax_forge.hjson`'s header comment; the ELF (sha256 `8cddf4e917539c67`), both `events.log` files, `tasks.json`, `manifest.json`, the streamer file and the window (304 cycles) came out byte-identical.
